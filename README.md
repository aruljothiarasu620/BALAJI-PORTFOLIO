# Balaji - Professional Video Editor Portfolio

A modern, high-performance portfolio website showcasing video editing work, reels, short-form and long-form content, client testimonials, and creative expertise.

## 🚀 Features

- **Dynamic Video Showcase**: Interactive reel previews, categorized video collections, and responsive media players.
- **Client Testimonials & Metrics**: Highlight client satisfaction, views generated, and project milestones.
- **Modern Responsive Design**: Built with Tailwind CSS and React for seamless viewing across desktop, tablet, and mobile.
- **Interactive UI**: Micro-interactions, animations, and celebratory effects.

## 🛠️ Tech Stack

- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Canvas Confetti**

## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aruljothiarasu620/BALAJI-PORTFOLIO.git
   cd BALAJI-PORTFOLIO
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
